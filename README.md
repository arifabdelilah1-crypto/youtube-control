# Short Viral

Multi-network dashboard for short and long videos: research, ideas, a video studio, animation styles,
scheduling and publishing for every network you connect.

## Setup and operations

The setup guide (servers, secrets, scheduled jobs, deployment) is private and kept by the maintainer.
No keys or secrets live in this repository.
